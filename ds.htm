1. What is Data Structure?
A data structure is a specialized format for organizing, processing, retrieving and storing data. It provides a way to manage large amounts of data efficiently for uses such as large databases and internet indexing services.
2. What is a Stack?
A stack is a linear data structure that follows the Last-In-First-Out (LIFO) principle. Elements are added (pushed) and removed (popped) from the same end, called the "top" of the stack.
3. What are the basic operations of a Stack?
The basic operations of a stack are:
  • Push: Add an element to the top of the stack
  • Pop: Remove the top element from the stack
  • Peek/Top: Return the top element without removing it
  • IsEmpty: Check if the stack is empty
4. What are the applications of Stack?
Applications of stack include:
  • Function call management in recursion
  • Expression evaluation and conversion (infix to postfix)
  • Undo functionality in text editors
  • Backtracking algorithms (maze solving, etc.)
  • Browser history management
5. How is a Stack implemented?
A stack can be implemented using:
  • Arrays: Fixed size, contiguous memory allocation
  • Linked Lists: Dynamic size, non-contiguous memory allocation
6. What is Stack Overflow and Underflow?
  • Stack Overflow: Occurs when trying to push an element onto a stack that is already full (in fixed-size implementations)
  • Stack Underflow: Occurs when trying to pop an element from an empty stack
7. What is the time complexity of stack operations?
For a properly implemented stack:
  • Push: O(1)
  • Pop: O(1)
  • Peek/Top: O(1)
  • IsEmpty: O(1)
8. How is Stack used in Expression Evaluation?
Stacks are used to evaluate expressions by:
  • Converting infix expressions to postfix (Reverse Polish Notation)
  • Evaluating postfix expressions using a stack to store operands
  • Handling operator precedence and parentheses
9. How does Recursion use Stack?
Recursion uses the system's call stack to:
  • Store the return address of each function call
  • Store local variables and parameters of each call
  • Manage the execution order of recursive calls
When a function calls itself, a new stack frame is pushed onto the call stack. When the function returns, the stack frame is popped.
10. What are the advantages of using Stack?
Advantages of using a stack:
  • Simple implementation with O(1) time complexity for basic operations
  • Efficient memory utilization (especially with linked list implementation)
  • Natural fit for problems requiring LIFO ordering
  • Essential for many algorithms and system operations

11. What is a queue in data structures?
A queue is a linear data structure that follows the First-In-First-Out (FIFO) principle. Elements are added at the rear (enqueue) and removed from the front (dequeue).
12. What are the basic operations of a queue?
The basic operations of a queue are:
  • Enqueue: Add an element to the rear of the queue
  • Dequeue: Remove an element from the front of the queue
  • Front/Peek: Return the front element without removing it
  • IsEmpty: Check if the queue is empty
  • IsFull: Check if the queue is full (for fixed-size implementations)
13. How is a queue implemented using arrays?
A queue can be implemented using an array by:
  • Maintaining two pointers: front and rear
  • Incrementing rear when enqueueing (if space available)
  • Incrementing front when dequeueing
  • Handling the wrap-around when rear reaches the end of the array (circular queue)
14. Simple Queue (Array) Code in C
#define MAX 100

int queue[MAX];
int front = -1, rear = -1;

// Enqueue operation
void enqueue(int value) {
    if (rear == MAX - 1) {
        printf("Queue Overflow\n");
        return;
    }
    if (front == -1) {
        front = 0;
    }
    queue[++rear] = value;
}

// Dequeue operation
int dequeue() {
    if (front == -1 || front > rear) {
        printf("Queue Underflow\n");
        return -1;
    }
    return queue[front++];
}

// Check if queue is empty
int isEmpty() {
    return front == -1 || front > rear;
}
15. What is a circular queue?
A circular queue is a queue implementation that connects the last position back to the first position to form a circle. This allows the queue to reuse the empty space created when elements are dequeued, overcoming the limitation of linear queues.
16. Formula to move rear in a circular queue
The formula to move the rear pointer in a circular queue is:
rear = (rear + 1) % SIZE
where SIZE is the maximum capacity of the queue.
17. What is a priority queue?
A priority queue is an abstract data type where each element has an associated priority. Elements with higher priority are served before elements with lower priority. It can be implemented using arrays, linked lists, or heaps.
18. What is a double-ended queue (deque)?
A double-ended queue (deque) is a linear data structure that allows insertion and deletion from both ends. It combines the properties of stacks and queues. Operations include:
  • Insertion at front and rear
  • Deletion from front and rear
19. Applications of Queue
Applications of queues include:
  • CPU scheduling in operating systems
  • Print job management
  • Handling requests in web servers
  • Breadth-First Search (BFS) algorithm
  • Buffering in data communication
  • Simulation of real-world queues (e.g., supermarket checkout)
20. Code to implement queue using linked list in C
struct Node {
    int data;
    struct Node* next;
};

struct Node* front = NULL;
struct Node* rear = NULL;

// Enqueue operation
void enqueue(int value) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = value;
    newNode->next = NULL;
    
    if (rear == NULL) {
        front = rear = newNode;
        return;
    }
    
    rear->next = newNode;
    rear = newNode;
}

// Dequeue operation
int dequeue() {
    if (front == NULL) {
        printf("Queue Underflow\n");
        return -1;
    }
    
    struct Node* temp = front;
    int value = temp->data;
    front = front->next;
    
    if (front == NULL) {
        rear = NULL;
    }
    
    free(temp);
    return value;
}
21. Can a queue be implemented using stacks? How?
Yes, a queue can be implemented using two stacks:
  • Method 1 (Making enqueue operation costly):
    • Use stack1 for enqueue operation
    • For dequeue, pop all elements from stack1 and push to stack2, then pop from stack2
    • Finally, pop all elements from stack2 back to stack1
  • Method 2 (Making dequeue operation costly):
    • Enqueue: Simply push to stack1
    • Dequeue: If stack2 is empty, pop all elements from stack1 and push to stack2, then pop from stack2
22. Can you implement a stack using queues?
Yes, a stack can be implemented using two queues:
  • Push operation:
    • Add the new element to queue2
    • Move all elements from queue1 to queue2
    • Swap the names of queue1 and queue2
  • Pop operation:
    • Simply dequeue from queue1
23. You are given a queue. How do you reverse it using a stack?
To reverse a queue using a stack:
  • Create an empty stack
  • Dequeue all elements from the queue and push them onto the stack
  • Pop all elements from the stack and enqueue them back into the queue
The queue will now be reversed.
24. What is common between stack and queue in terms of implementation?
Common aspects in stack and queue implementation:
  • Both can be implemented using arrays or linked lists
  • Both have O(1) time complexity for basic operations
  • Both require handling of overflow and underflow conditions
  • Both are linear data structures
25. Which is better for undo functionality – stack or queue?
A stack is better for undo functionality because:
  • It follows LIFO (Last-In-First-Out) order, which matches the natural behavior of undo operations
  • The most recent action should be undone first
  • Stacks provide O(1) time complexity for push (recording action) and pop (undoing action)
26. How would you check if a string is a palindrome using stack and queue?
To check if a string is a palindrome using stack and queue:
  • Push each character of the string onto a stack
  • Enqueue each character of the string into a queue
  • Pop from the stack and dequeue from the queue simultaneously, comparing each character
  • If all characters match, the string is a palindrome
The stack reverses the order while the queue maintains the original order.
27. Can you implement BFS using a stack instead of a queue?
No, BFS (Breadth-First Search) cannot be implemented using a stack because:
  • BFS requires exploring all neighbors at the present depth before moving to the next level
  • Queues follow FIFO (First-In-First-Out) order, which is essential for BFS
  • Stacks follow LIFO (Last-In-First-Out) order, which would implement DFS (Depth-First Search) instead
28. What happens if you try to dequeue from an empty queue?
Attempting to dequeue from an empty queue results in a queue underflow condition. This is an error state that should be handled by:
  • Checking if the queue is empty before dequeueing
  • Returning an error value or throwing an exception
  • Displaying an appropriate error message
29. Stack is LIFO. What if we want the oldest element?
If you need to access the oldest (first) element in a LIFO structure, you have several options:
  • Pop all elements until you reach the oldest one (inefficient)
  • Use a different data structure like a queue (FIFO)
  • Use a deque that allows access to both ends
  • Use a linked list with a pointer to both head and tail
30. Why is a stack used in infix to postfix conversion?
A stack is used in infix to postfix conversion because:
  • It helps handle operator precedence and associativity
  • It stores operators temporarily until their operands are processed
  • It allows parentheses to be handled naturally
  • The LIFO property ensures that higher precedence operators are processed first
31. Convert this infix expression to postfix: A + B * C - D
To convert "A + B * C - D" to postfix:
  • Process A: Output A
  • Process +: Push to stack
  • Process B: Output B
  • Process *: Higher precedence than +, so push to stack
  • Process C: Output C
  • Process -: Pop * (higher precedence), output *, then pop + (same precedence), output +, then push -
  • Process D: Output D
  • Pop remaining - from stack
Result: A B C * + D -
32. What is the postfix form of: (A + B) * (C - D)?
To convert "(A + B) * (C - D)" to postfix:
  • Process (: Push to stack
  • Process A: Output A
  • Process +: Push to stack
  • Process B: Output B
  • Process ): Pop +, output +
  • Process *: Push to stack
  • Process (: Push to stack
  • Process C: Output C
  • Process -: Push to stack
  • Process D: Output D
  • Process ): Pop -, output -
  • Pop * from stack
Result: A B + C D - *
33. What will be the result of this postfix expression? 5 6 2 + * 12 4 / -
Evaluating "5 6 2 + * 12 4 / -":
  • Read 5: Push 5
  • Read 6: Push 6
  • Read 2: Push 2
  • Read +: Pop 2 and 6, compute 6 + 2 = 8, push 8
  • Read *: Pop 8 and 5, compute 5 * 8 = 40, push 40
  • Read 12: Push 12
  • Read 4: Push 4
  • Read /: Pop 4 and 12, compute 12 / 4 = 3, push 3
  • Read -: Pop 3 and 40, compute 40 - 3 = 37, push 37
Result: 37

34. What is a Linked List?
A linked list is a linear data structure where elements are not stored at contiguous memory locations. Instead, each element (node) contains a data part and a pointer (or reference) to the next node in the sequence.
35. What are the types of Linked Lists?
Types of linked lists include:
  • Singly Linked List: Each node has a pointer to the next node
  • Doubly Linked List: Each node has pointers to both next and previous nodes
  • Circular Linked List: The last node points back to the first node
  • Circular Doubly Linked List: Combines properties of doubly and circular linked lists
36. Structure of a Node in Singly Linked List
struct Node {
    int data;           // Data part of the node
    struct Node* next;  // Pointer to the next node
};
37. How do you insert a node at the beginning of a Singly Linked List?
To insert a node at the beginning of a singly linked list:
  • Create a new node
  • Set the new node's next pointer to the current head
  • Update the head pointer to point to the new node
void insertAtBeginning(int value) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = value;
    newNode->next = head;
    head = newNode;
}
38. How do you insert a node at the end of a Singly Linked List?
To insert a node at the end of a singly linked list:
  • Create a new node
  • If the list is empty, set head to the new node
  • Otherwise, traverse to the last node
  • Set the last node's next pointer to the new node
void insertAtEnd(int value) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = value;
    newNode->next = NULL;
    
    if (head == NULL) {
        head = newNode;
        return;
    }
    
    struct Node* temp = head;
    while (temp->next != NULL) {
        temp = temp->next;
    }
    temp->next = newNode;
}
39. How do you delete a node with a specific value?
To delete a node with a specific value:
  • Traverse the list to find the node with the given value
  • Keep track of the previous node
  • Set the previous node's next pointer to the node after the one to be deleted
  • Free the memory of the deleted node
void deleteNode(int value) {
    struct Node* temp = head;
    struct Node* prev = NULL;
    
    // If the node to be deleted is the head
    if (temp != NULL && temp->data == value) {
        head = temp->next;
        free(temp);
        return;
    }
    
    // Search for the node to be deleted
    while (temp != NULL && temp->data != value) {
        prev = temp;
        temp = temp->next;
    }
    
    // If node not found
    if (temp == NULL) return;
    
    // Unlink the node
    prev->next = temp->next;
    free(temp);
}
40. How do you reverse a singly linked list?
To reverse a singly linked list:
  • Initialize three pointers: prev, current, and next
  • Traverse the list, changing each node's next pointer to point to the previous node
  • Update the head pointer to the last node
void reverseList() {
    struct Node* prev = NULL;
    struct Node* current = head;
    struct Node* next = NULL;
    
    while (current != NULL) {
        next = current->next;
        current->next = prev;
        prev = current;
        current = next;
    }
    head = prev;
}
41. How do you make a Circular Linked List?
To make a circular linked list:
  • Create a singly linked list
  • Traverse to the last node
  • Set the last node's next pointer to point back to the head node
void makeCircular() {
    if (head == NULL) return;
    
    struct Node* temp = head;
    while (temp->next != NULL) {
        temp = temp->next;
    }
    temp->next = head;  // Make it circular
}
42. What happens if you forget to update the head pointer after inserting?
If you forget to update the head pointer after inserting at the beginning:
  • The new node will be created but not connected to the list
  • The list will remain unchanged from the head's perspective
  • The new node will be "orphaned" and eventually cause a memory leak
  • Any operations on the list will not include the new node
43. What are real-life uses of Linked Lists?
Real-life uses of linked lists include:
  • Web browser history (forward and back navigation)
  • Music playlists (next and previous track)
  • Image viewers (next and previous image)
  • Dynamic memory allocation
  • Implementation of other data structures (stacks, queues, graphs)
  • Operating system process scheduling
44. You are at the last node of a singly linked list. Can you go back to the previous node?
No, you cannot directly go back to the previous node in a singly linked list because:
  • Each node only has a pointer to the next node, not the previous one
  • To access the previous node, you would need to traverse the list from the head again
  • This is O(n) operation and inefficient for large lists
For bidirectional traversal, a doubly linked list is needed.
45. What happens if you delete the head node in a singly linked list?
When deleting the head node in a singly linked list:
  • The head pointer must be updated to point to the next node
  • Memory of the original head node should be freed
  • If not handled properly, it can cause:
    • Memory leaks
    • Dangling pointers
    • Loss of access to the rest of the list
46. Which is more memory efficient – SLL or DLL?
Singly Linked List (SLL) is more memory efficient than Doubly Linked List (DLL) because:
  • SLL nodes have only one pointer (next)
  • DLL nodes have two pointers (next and prev)
  • For the same number of nodes, SLL uses less memory
  • Example: For 1000 nodes with 4-byte data and 4-byte pointers:
    • SLL: 1000 × (4 + 4) = 8000 bytes
    • DLL: 1000 × (4 + 4 + 4) = 12000 bytes
47. What is the minimum number of pointers required to implement a doubly linked list?
The minimum number of pointers required to implement a doubly linked list is two:
  • next pointer: Points to the next node in the sequence
  • prev pointer: Points to the previous node in the sequence
48. Can you implement a circular singly linked list using just one pointer?
Yes, you can implement a circular singly linked list using just one pointer (the next pointer) because:
  • In a circular singly linked list, the last node's next pointer points back to the head
  • No additional pointers are needed for the circular connection
  • The same structure as a regular singly linked list, just with the last node pointing to the first
49. Can a node in a doubly linked list point to itself in both prev and next?
Yes, a node in a doubly linked list can point to itself in both prev and next pointers. This would create a self-referential node that forms a circular list with only one node. However, this is generally not useful in practice as it creates a loop with no other nodes.
50. What happens if we forget to update prev in DLL while inserting a node?
If you forget to update the prev pointer in a doubly linked list while inserting a node:
  • The backward traversal will be broken
  • The new node will not be accessible from its previous node
  • The list will appear corrupted when traversed backward
  • Operations that rely on the prev pointer will fail
51. Which is easier to implement recursively — SLL or DLL?
Singly Linked List (SLL) is generally easier to implement recursively than Doubly Linked List (DLL) because:
  • Recursive operations naturally follow the forward direction (next pointer)
  • With DLL, you would need to handle both directions, complicating the recursion
  • Most recursive list operations (traversal, search, insertion at end) are simpler with SLL
52. Can a DLL be circular too? What changes are needed?
Yes, a Doubly Linked List (DLL) can be circular. The changes needed are:
  • The head node's prev pointer should point to the tail node
  • The tail node's next pointer should point to the head node
  • This creates a bidirectional circular structure
This is called a Circular Doubly Linked List.
53. Which is better for implementing browser history: SLL or DLL?
Doubly Linked List (DLL) is better for implementing browser history because:
  • Browser history requires both forward and backward navigation
  • DLL provides O(1) time complexity for both next and previous operations
  • With SLL, going back to a previous page would require traversing from the beginning (O(n))

59. If you continuously use First-Fit allocation, what kind of memory problem are you likely to face over time?
With continuous use of First-Fit allocation, you are likely to face external fragmentation over time. This occurs because:
  • Small memory holes are scattered throughout the memory
  • These holes may be too small to satisfy new allocation requests
  • Even though the total free memory might be sufficient, it's fragmented into non-contiguous blocks
60. What is garbage collection in memory management? Is it proactive or reactive?
Garbage collection is an automatic memory management process that:
  • Identifies and reclaims memory that is no longer in use by the program
  • Frees up resources occupied by objects that are no longer accessible
  • Prevents memory leaks by automatically deallocating unused memory
Garbage collection is reactive because it responds to memory allocation needs rather than proactively managing memory.
61. Is garbage collection used in C/C++? Why or why not?
No, garbage collection is not typically used in C/C++ because:
  • C/C++ prioritize performance and control over memory management
  • They provide manual memory management (malloc/free, new/delete)
  • Garbage collection introduces overhead and unpredictability
  • C/C++ are designed for systems programming where direct memory control is essential
However, some C/C++ libraries or frameworks may implement their own garbage collection mechanisms.
62. What is a tree?
A tree is a hierarchical data structure consisting of nodes connected by edges. It has:
  • A root node (topmost node)
  • Zero or more child nodes
  • Edges connecting parent nodes to child nodes
  • No cycles (acyclic)
  • All nodes except the root have exactly one parent
63. How is a binary tree different from a general tree?
Differences between binary tree and general tree:
Feature Binary Tree General Tree
Number of children Maximum 2 children per node No limit on number of children
Child ordering Left and right children are ordered Children are unordered
Empty tree Can be empty (no nodes) Must have at least one node (root)
64. What are the types of binary trees?
Types of binary trees:
  • Full Binary Tree: Every node has 0 or 2 children
  • Complete Binary Tree: All levels are completely filled except possibly the last, which is filled from left to right
  • Perfect Binary Tree: All internal nodes have 2 children and all leaves are at the same level
  • Balanced Binary Tree: Height of tree is O(log n) where n is number of nodes
  • Degenerate Tree: Each parent node has only one child (similar to linked list)
65. What are the properties of a binary tree with n nodes?
Properties of a binary tree with n nodes:
  • Minimum number of levels: 1 (all nodes in a single path)
  • Maximum number of levels: n (each node has one child)
  • Maximum number of nodes at level i: 2^(i-1)
  • Maximum number of nodes in a tree of height h: 2^h - 1
  • For a non-empty binary tree: n = n₀ + n₁ + n₂, where n₀, n₁, n₂ are number of nodes with 0, 1, 2 children respectively
  • n₀ = n₂ + 1 (number of leaf nodes = number of nodes with 2 children + 1)
66. What are the methods to represent a binary tree?
Methods to represent a binary tree:
  • Array Representation:
    • Store nodes in an array level by level
    • For node at index i:
      • Left child: 2i + 1
      • Right child: 2i + 2
      • Parent: floor((i-1)/2)
  • Linked Representation:
    • Each node contains data and pointers to left and right children
    • More flexible for dynamic trees
67. What are the tree traversal methods?
Tree traversal methods:
  • Depth-First Traversals:
    • Inorder (Left-Root-Right): Traverse left subtree, visit root, traverse right subtree
    • Preorder (Root-Left-Right): Visit root, traverse left subtree, traverse right subtree
    • Postorder (Left-Right-Root): Traverse left subtree, traverse right subtree, visit root
  • Breadth-First Traversal:
    • Level Order: Visit nodes level by level from top to bottom
68. What is an expression tree?
An expression tree is a binary tree where:
  • Internal nodes represent operators (+, -, *, /, etc.)
  • Leaf nodes represent operands (constants or variables)
  • The tree structure represents the precedence of operations
Traversing an expression tree in different orders gives different expression formats:
  • Inorder traversal: Infix expression
  • Preorder traversal: Prefix expression
  • Postorder traversal: Postfix expression
69. What is a Binary Search Tree (BST)?
A Binary Search Tree (BST) is a binary tree with the following properties:
  • For each node, all values in its left subtree are less than the node's value
  • For each node, all values in its right subtree are greater than the node's value
  • Both left and right subtrees are also binary search trees
  • There are no duplicate values (in most implementations)
70. What are the main operations on a BST?
Main operations on a BST:
  • Search: Find a value in the tree (O(h) time, where h is height)
  • Insertion: Add a new value to the tree (O(h) time)
  • Deletion: Remove a value from the tree (O(h) time)
  • Traversal: Visit all nodes in a specific order (O(n) time)
  • Find Minimum/Maximum: Find smallest/largest value (O(h) time)
71. What is a Binary Heap?
A Binary Heap is a complete binary tree that satisfies the heap property:
  • Min-Heap: Parent node's value is less than or equal to its children's values
  • Max-Heap: Parent node's value is greater than or equal to its children's values
Binary Heaps are commonly used to implement priority queues.
72. What are priority queues and how are they implemented?
A priority queue is an abstract data type where each element has an associated priority. Elements with higher priority are served before elements with lower priority. Implementation methods:
  • Array: O(1) insertion, O(n) extraction of highest priority
  • Sorted Array: O(n) insertion, O(1) extraction
  • Linked List: Similar to array implementation
  • Binary Heap: O(log n) for both insertion and extraction (most efficient)
82. If a binary tree has n nodes, what's the maximum number of leaf nodes it can have?
In a binary tree with n nodes, the maximum number of leaf nodes is (n+1)/2. This occurs in a perfect binary tree where:
  • All levels are completely filled
  • All internal nodes have exactly 2 children
  • For a perfect binary tree with height h: n = 2^h - 1 and leaves = 2^(h-1) = (n+1)/2
83. Which tree traversal is used for expression evaluation? Which one for conversion?
  • Expression Evaluation: Postorder traversal is used because it processes operands before operators, which matches the natural evaluation order of expressions.
  • Expression Conversion:
    • Infix to Prefix: Preorder traversal
    • Infix to Postfix: Postorder traversal

85. Which is better for finding shortest path in an unweighted graph: BFS or DFS?
BFS (Breadth-First Search) is better for finding the shortest path in an unweighted graph because:
  • BFS explores all nodes at the present depth level before moving to nodes at the next depth level
  • It guarantees that the first time a node is discovered, it is via the shortest path from the source
  • DFS may go deep into one branch and miss shorter paths
86. Can a disconnected graph have a spanning tree?
No, a disconnected graph cannot have a single spanning tree. However:
  • Each connected component of a disconnected graph can have its own spanning tree
  • The collection of these spanning trees is called a spanning forest
  • A spanning tree by definition must connect all vertices of the graph, which is impossible in a disconnected graph

  • B and C are directly connected to A (at the same level)
  • D is at the next level, connected to either B or C (or both)

    • B connected to D

  • Or both B and C could be connected to D

73. What is a graph?
A graph is a non-linear data structure consisting of:
  • Vertices (Nodes): Represent entities or objects
  • Edges: Connections between vertices
Graphs can be:
  • Directed: Edges have a direction (from one vertex to another)
  • Undirected: Edges have no direction (bidirectional)
  • Weighted: Edges have associated weights or costs
  • Unweighted: Edges have no weights
74. How can you represent graphs?
Graph representation methods:
  • Adjacency Matrix:
    • 2D array where matrix[i][j] represents an edge from vertex i to vertex j
    • For weighted graphs, matrix[i][j] stores the weight of the edge
    • Space complexity: O(V²) where V is number of vertices
  • Adjacency List:
    • Array of linked lists where each list represents the neighbors of a vertex
    • For weighted graphs, each list element stores both neighbor vertex and edge weight
    • Space complexity: O(V+E) where V is vertices and E is edges
  • Incidence Matrix:
    • 2D array where rows represent vertices and columns represent edges
    • Each entry indicates whether a vertex is incident to an edge
75. What is Depth First Search (DFS)?
Depth First Search (DFS) is a graph traversal algorithm that:
  • Explores as far as possible along each branch before backtracking
  • Uses a stack (either explicitly or implicitly via recursion)
  • Time complexity: O(V+E) where V is vertices and E is edges
  • Space complexity: O(V) for the stack/recursion
DFS is used for:
  • Finding connected components
  • Topological sorting
  • Solving puzzles with one solution (mazes, etc.)
  • Detecting cycles in a graph
76. What is Breadth First Search (BFS)?
Breadth First Search (BFS) is a graph traversal algorithm that:
  • Explores all vertices at the present depth level before moving to vertices at the next depth level
  • Uses a queue to manage the vertices to visit
  • Time complexity: O(V+E) where V is vertices and E is edges
  • Space complexity: O(V) for the queue
BFS is used for:
  • Finding shortest path in unweighted graphs
  • Finding connected components
  • Web crawling
  • Social networking features (finding friends within a certain distance)

78. What is Single Source All Destination in Graphs?
Single Source All Destination (also known as Single Source Shortest Path) is a graph problem that:
  • Finds the shortest path from a given source vertex to all other vertices in the graph
  • Can be solved using algorithms like:
    • Dijkstra's algorithm (for weighted graphs with non-negative weights)
    • Bellman-Ford algorithm (for weighted graphs with negative weights)
    • BFS (for unweighted graphs)
  • Applications include routing protocols, navigation systems, and network analysis

80. How do you detect a cycle in a graph?
Methods to detect cycles in a graph:
  • For Undirected Graphs:
    • Use DFS or BFS
    • Keep track of visited vertices
    • If you encounter an adjacent vertex that is visited and is not the parent of the current vertex, there is a cycle
  • For Directed Graphs:
    • Use DFS with recursion stack
    • Mark vertices as:
      • Unvisited
      • Visiting (in recursion stack)
      • Visited (not in recursion stack)
    • If you encounter a vertex that is currently in the recursion stack, there is a cycle
  • Union-Find (Disjoint Set Union):
    • Works for undirected graphs
    • For each edge, check if the two vertices are in the same set
    • If they are, there is a cycle
81. How do you find connected components in a graph?
To find connected components in a graph:
  • For Undirected Graphs:
    • Use BFS or DFS
    • Start from an unvisited vertex and traverse all reachable vertices
    • Mark them as visited and count as one component
    • Repeat for all unvisited vertices
  • For Directed Graphs:
    • Find strongly connected components (SCCs) using Kosaraju's algorithm or Tarjan's algorithm
    • Kosaraju's algorithm:
      • Perform DFS on the original graph
      • Transpose the graph (reverse all edges)
      • Perform DFS on the transposed graph in order of decreasing finishing times

89. What is the basic idea of Selection Sort?
The basic idea of Selection Sort is:
  • Divide the array into a sorted portion (left) and an unsorted portion (right)
  • Find the smallest element in the unsorted portion
  • Swap it with the first element of the unsorted portion
  • Move the boundary between sorted and unsorted portions one element to the right
  • Repeat until the entire array is sorted
Time Complexity: O(n²) in all cases
Space Complexity: O(1)
90. Is Insertion Sort better than Selection Sort?
Insertion Sort is generally better than Selection Sort in the following scenarios:
  • For nearly sorted arrays: Insertion Sort performs better (O(n) vs O(n²))
  • For small datasets: Both have similar performance, but Insertion Sort has lower overhead
  • Adaptive nature: Insertion Sort is adaptive (takes advantage of existing order)
However, Selection Sort has the advantage of:
  • Minimum number of swaps (O(n) swaps)
  • Better performance when writing to memory is expensive
91. Which sorting algorithm is best for small datasets?
For small datasets, the best sorting algorithms are:
  • Insertion Sort:
    • Simple implementation
    • Low overhead
    • Efficient for small or nearly sorted arrays
  • Selection Sort:
    • Simple implementation
    • Minimum number of swaps
Many standard libraries use Insertion Sort for small subarrays within more complex algorithms like QuickSort.
100. Which is faster: Merge Sort or Quick Sort?
The speed comparison between Merge Sort and Quick Sort depends on several factors:
Factor Merge Sort Quick Sort
Average Time Complexity O(n log n) O(n log n)
Worst Case Time Complexity O(n log n) O(n²)
Space Complexity O(n) O(log n) (recursion stack)
Cache Performance Poor (non-sequential access) Good (sequential access)
Stability Stable Not stable (standard implementation)
In practice:
  • Quick Sort is generally faster for average cases due to better cache performance and lower constant factors
  • Merge Sort is preferred when stability is required or when worst-case performance must be guaranteed
  • Hybrid approaches (like Introsort) combine Quick Sort with other algorithms to avoid worst-case scenarios
92. How does Binary Search work?
Binary Search works on sorted arrays by:
  • Comparing the target value with the middle element of the array
  • If the target matches the middle element, return its index
  • If the target is less than the middle element, search in the left half
  • If the target is greater than the middle element, search in the right half
  • Repeat until the target is found or the search space is empty
Time Complexity: O(log n)
Space Complexity: O(1) (iterative) or O(log n) (recursive)
93. Can Binary Search be used on a linked list?
No, Binary Search cannot be efficiently used on a linked list because:
  • Binary Search requires random access to elements (O(1) access time)
  • Linked lists only allow sequential access (O(n) access time)
  • Finding the middle element in a linked list requires traversing half the list
  • This would make the overall time complexity O(n log n), which is worse than a simple linear search (O(n))

94. What is hashing?
Hashing is a technique that:
  • Maps data of arbitrary size to fixed-size values (hash codes)
  • Uses a hash function to compute an index into an array of buckets
  • Enables efficient data retrieval in constant time on average
  • Forms the basis of hash tables, hash maps, and similar data structures
Key properties of a good hash function:
  • Deterministic (same input always produces same output)
  • Uniform distribution (minimizes collisions)
  • Efficient to compute
95. What are common hash functions?
Common hash functions include:
  • Division Method: h(k) = k mod m, where m is the table size
  • Multiplication Method: h(k) = floor(m * (k * A mod 1)), where A is a constant (0 < A < 1)
  • Mid-Square Method: Square the key, then extract the middle digits
  • Folding Method: Divide the key into parts, add them together
  • Polynomial Rolling Hash: Used for strings and variable-length data
  • Cryptographic Hash Functions: MD5, SHA-1, SHA-256 (used for security)
96. What is a collision? How is it resolved?
A collision occurs when two different keys hash to the same index in a hash table. Collision resolution techniques:
  • Separate Chaining:
    • Each bucket contains a linked list of all elements that hash to that index
    • New elements are added to the end of the list
  • Open Addressing:
    • Linear Probing: Check the next bucket (h(k) + i) mod m
    • Quadratic Probing: Check buckets at (h(k) + i²) mod m
    • Double Hashing: Use a second hash function to determine the step size

    99. What is the load factor in hashing?
    The load factor in hashing is defined as:
    λ = n / m
    where:
    • n = number of elements in the hash table
    • m = number of buckets in the hash table
    Significance of load factor:
    • Measures how full the hash table is
    • Affects performance:
      • Lower load factor: fewer collisions, faster operations
      • Higher load factor: more collisions, slower operations
    • Triggers resizing:
      • Typically, when λ > 0.7, the hash table is resized
      • Resizing involves creating a larger table and rehashing all elements
